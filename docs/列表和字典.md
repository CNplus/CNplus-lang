# 列表和字典

程序经常要一次记住**一堆**东西，而不是一个。列表和字典就是干这个的。

## 列表：一串按顺序排的东西

```
设 同学们 = ["小明", "小红", "小刚"]
```

- 用**位置**取出里面的东西，位置从 0 开始数：

```
打印(同学们[0])      # 小明（第 1 个，位置是 0）
打印(同学们[2])      # 小刚
```

> 为什么从 0 开始？这是几乎所有编程语言的约定，习惯就好：
> 第 1 个是 0 号，第 2 个是 1 号……

- 逐个处理用「遍历…每个…」：

```
遍历 同学们 每个 名字
    打印("你好，" + 名字)
```

- 常用操作：

| 想做的事 | 怎么写 |
|---|---|
| 有几个 | `长度(同学们)` |
| 末尾加一个 | `追加(同学们, "小美")` |
| 删掉某个 | `移除(同学们, "小明")` |
| 排序 | `排序(同学们)` |
| 求和（数字列表） | `求和([1, 2, 3])` |
| 最大 / 最小 | `最大([3, 7, 2])` |

## 字典：成对的对应关系

字典像一本**通讯录**：左边是名字，右边是电话，用名字查电话。

```
设 电话本 = {"小明": "138xxxx", "小红": "139xxxx"}
打印(电话本["小明"])      # 138xxxx
```

左边那个用来查找的东西，我们叫它**标签**（就像贴在每个电话上的名字标签）。
右边查出来的东西叫**值**。

```
设 成绩 = {"小明": 85, "小红": 92}
打印(成绩["小明"])       # 85 —— 用标签「小明」查出值 85
```

- 加一对 / 改一个：

```
成绩["小刚"] = 78        # 加一个新的
成绩["小明"] = 90        # 改已有的
```

- 逐个处理，直接遍历就能拿到每个标签：

```
遍历 成绩 每个 名字
    打印(名字 + " 考了 " + 文本(成绩[名字]) + " 分")
```

- 常用操作：

| 想做的事 | 怎么写 |
|---|---|
| 所有标签 | `所有标签(成绩)` |
| 所有值 | `所有值(成绩)` |
| 有没有某标签 | `有标签(成绩, "小明")` |
| 删掉某标签 | `删标签(成绩, "小明")` |
| 有几对 | `长度(成绩)` |

## 列表还是字典？

- 只是**排队**、看重顺序 → 用**列表**（`[…]`）
- 要用**名字查东西**、成对对应 → 用**字典**（`{…}`）
