# 让程序和人对话

只会输出的程序是"死"的。用「询问」和「询问数值」，程序就能听你说话。

## 问：要一段文字

```
设 名字 = 询问("你叫什么名字？")
打印(填"你好，{名字}！")
```

运行时会停下来等你敲字，按回车后继续。`问` 拿回来的**永远是文字**，
即使你输入 `123`，它也是文字 `"123"` 而不是数字 123。

不想要提示语就直接 `询问()`。

## 询问数值：要一个数字

```
设 年龄 = 询问数值("你多大了？")
打印(填"明年你就 {年龄 + 1} 岁了")
```

`询问数值` 会帮你把文字转成数字，而且**输错会自动重问**：

```
你多大了？abc
「abc」不是数字，请重新输入。
你多大了？18
```

输入 `1.5` 会得到小数，输入 `18` 会得到整数。

## 为什么分成两个

因为「文字」和「数字」是两类不同的东西（见 [列表和字典](列表和字典.md)）：

```
设 a = 询问()        # 输入 5，a 是文字 "5"
设 b = 询问数值()     # 输入 5，b 是数字 5
打印(a + a)        # "55"  ← 文字接起来
打印(b + b)        # 10    ← 数字相加
```

想把 `问` 拿到的文字变成数字，用 `整数(…)` 或 `小数(…)`。

## 一个能玩的例子

`示例/07-猜数字.cnp` 是真的可以玩的猜数字游戏：

```
设 答案 = 随机数(1, 100)
循环 真
    设 猜 = 询问数值("请输入你猜的数字：")
    如果 猜 == 答案
        打印("猜中了！")
        跳出
    否则 如果 猜 < 答案
        打印("小了，再大一点")
    否则
        打印("大了，再小一点")
```

运行：`python -m cnplus 运行 示例/07-猜数字.cnp`

## 输入结束了怎么办

如果程序还想要输入、但输入已经没了（比如你按了 Ctrl+D，
或者用管道喂数据喂少了），`询问数值` 会报错停下：

```
错误[CN0310]: 还需要一个数字，但输入已经结束了
```

这是**故意的**：早期版本这里会陷入死循环，程序卡死。
报错停下比卡住好。
