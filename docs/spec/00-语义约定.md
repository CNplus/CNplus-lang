# CNplus 语义约定

> **状态**：v0.1.0 已实现。本文件是规范，实现必须服从它。
> **为什么重要**：见总纲第三节「语义泄漏防御」。转译到 Python 会让 CNplus
> 悄悄继承 Python 的语义。测试必须断言**这里规定的行为**，而不是观察到的宿主行为。

---

## 一、值与类型

CNplus 有六类值：

| 类型 | 字面量 | 说明 |
|---|---|---|
| 整数 | `1` `-42` | 任意精度 |
| 小数 | `1.5` `3.0` | IEEE 754 双精度 |
| 字符串 | `"你好"` `'你好'` | 不可变，Unicode 码点序列 |
| 布尔 | `真` `假` | |
| 空 | `空` | |
| 函数 | `函数 f() ...` | 一等公民，可作值传递 |

`类型(值)` 返回中文类型名：`"整数"` `"小数"` `"字符串"` `"布尔"` `"空"` `"函数"`。

**显示规则**：布尔显示为 `真`/`假`（不是 `True`/`False`），空显示为 `空`，
小数保留小数点（`3.0` 不显示成 `3`）。

---

## 二、真值 —— 故意与 Python 不同

> **只有布尔值能出现在条件位置。**

```
如果 0          # 错误 CN0301：条件必须是布尔值，这里是整数
如果 ""         # 错误 CN0301
如果 x != 0     # 正确
```

**理由**：Python 的隐式真值是初学者头号坑源（`if []` 与 `if [0]` 行为相反）。
CNplus 面向初学者，宁可多打几个字也要让条件的意图显式。

这条同时适用于 `如果`、`循环`，以及 `与`/`或`/`非` 的操作数。

**双重检查**：字面量条件在**静态检查**期报错（编辑器里直接红波浪线），
非字面量在**求值**期报错。两条路径同一个诊断码。

---

## 三、相等与比较 —— 故意与 Python 不同

| 表达式 | CNplus | Python |
|---|---|---|
| `1 == 1.0` | `真` | `True` |
| `1 == "1"` | **错误 CN0303** | `False` |
| `真 == 1` | **错误 CN0303** | `True` |
| `空 == 空` | `真` | `True` |
| `"a" < "b"` | `真` | `True` |
| `1 < "a"` | **错误 CN0303** | 报错 |

**规则**：
- 数字之间可比（整数与小数互通）
- 字符串之间可比
- 布尔只能与布尔比
- `空` 可与任何值比相等（但不能比大小）
- 其余跨类型比较一律报错，**不返回假**

**理由**：`1 == "1"` 悄悄返回假是 bug 的温床。报错让问题当场暴露。

## 四、算术

| 运算 | 规则 |
|---|---|
| `+` | 数字相加；字符串拼接。数字与字符串相加**报错** |
| `-` `*` | 仅数字。`"哈" * 3` 是例外，字符串重复 |
| `/` | **恒为小数**。`4 / 2` 得 `2.0` 不是 `2` |
| `//` | 向下取整 |
| `%` | 取余 |
| 除数为零 | 报错 CN0304（`/` `//` `%` 都是） |

整数运算任意精度，不溢出。

---

## 五、作用域

- 函数体是新作用域
- `令 x = ...` 声明本地变量；同一作用域内重复声明报错 CN0307
- `x = ...` 赋值给已存在的变量；变量不存在报错 CN0302
- 内层可读外层（闭包）
- 修改外层变量需要 `外部 x = ...`
- 读未声明变量报错 CN0302（静态检查期就能发现）

块（`如果`/`循环` 的主体）也是新作用域：

```
如果 真
    令 x = 1
如果 真
    令 x = 2      # 不冲突，两个不同的块作用域
```

**函数前向引用**：顶层函数可以互相调用，与定义顺序无关。

---

## 六、求值顺序

严格从左到右，包括函数实参。

`与`/`或` **短路**：
- `甲 与 乙` —— 甲为假时不求值乙
- `甲 或 乙` —— 甲为真时不求值乙

但两侧仍都必须是布尔 —— **短路跳过的一侧不检查**：

```
打印(真 或 1)      # 得 真。右侧未求值，故 1 的类型错误不触发
打印(真 与 1)      # 错误 CN0303。右侧被求值了
```

这是短路语义的必然代价：未执行的代码没有值可检查。静态检查同理，
不下钻到短路右侧（否则 `真 或 1 / 0` 会被误报为除以零）。

## 七、错误

所有错误携带：
- **稳定诊断码**（`CN0301` 等，一旦发布不改含义）
- **精确跨度**（行、列、偏移）
- **中文消息**
- 尽可能附**修复提示**

诊断码分段：

| 段 | 含义 |
|---|---|
| `CN01xx` | 词法 |
| `CN02xx` | 语法 |
| `CN03xx` | 语义 / 运行时 |

完整列表见 [`03-诊断码.md`](03-诊断码.md)。

---

## 八、未定义行为

以下情况**当前由宿主语言决定**，不保证跨后端一致。用户不应依赖：

- 超大整数的性能特征
- 小数的精确舍入行为（依赖 IEEE 754 实现）
- 递归深度上限
- 字典/集合的迭代顺序（尚未引入这些类型）
- `随机数` 的具体算法与种子行为

> 阶段 4 换成自有 VM 时，这些是允许变化的地方。凡在此列出的行为，
> 黄金语料不得断言。
