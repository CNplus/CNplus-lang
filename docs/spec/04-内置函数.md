# 内置函数语义合同

本文规定 CNplus 当前登记的 36 个内置函数。三个后端必须登记相同名字，并遵守同一行为；宿主 Python 或 JavaScript 的同名函数不是裁判。

## 共同规则

- 实参从左到右各求值一次。
- 参数数量不符报告 `CN0306`；参数类型不合报告 `CN0303`。
- 列表单个位置不存在或直接读取不存在的字典标签时报告 `CN0308`；`有标签`、`删标签`用于安全探测或删除，不因标签不存在而报错。
- 所有“位置”“位数”和范围端点只接受整数；布尔和小数都不是整数位置。
- 文字的长度、分割和查找位置按 Unicode 码点计算，不按 UTF-16 单元计算。
- 会修改列表或字典的函数返回 `空`，除非下表另有说明。

## 输入、输出和控制

| 函数 | 参数 | 合同 |
|---|---|---|
| `打印` | `值…` | 各值按 CNplus 显示格式输出，以空格隔开并换行。 |
| `询问` | `[提示]` | 显示可选提示，读取一行文字；输入结束返回空文字。 |
| `询问数值` | `[提示]` | 读取并转换成整数或小数；不是数值时提示并重询问，输入结束报告 `CN0310`。 |
| `随机数` | `起, 止` | 数值端点先向零截断，返回闭区间 `[起, 止]` 内的整数；截断后起点大于终点报告 `CN0303`。 |

## 转换和查看

| 函数 | 参数 | 合同 |
|---|---|---|
| `文本` | `值` | 返回 CNplus 显示文字。 |
| `整数` | `值` | 整数原样返回；小数向零截断；可解析文字转整数，否则报告 `CN0303`。 |
| `小数` | `值` | 数值或可解析文字转 IEEE 754 小数；溢出或无效值报告 `CN0303`。 |
| `类型` | `值` | 返回 CNplus 类型名；语言内置也属于 `函数`。 |

## 数值和范围

| 函数 | 参数 | 合同 |
|---|---|---|
| `绝对值` | `数值` | 返回绝对值，保持整数或小数类别。 |
| `四舍五入` | `数值[, 位数]` | 恰好在中点时远离 0；省略位数返回整数，指定整数位数时保持输入的整数/小数类别。 |
| `平方根` | `数值` | 返回实数平方根；负数报告 `CN0303`。 |
| `最大` | `值…` 或 `列表/文字` | 只比较数值或只比较文字；单个文字按码点序列处理；空输入或跨类型报告 `CN0303`。 |
| `最小` | `值…` 或 `列表/文字` | 与 `最大` 相同，取最小值。 |
| `求和` | `列表` | 列表必须全是数值；整数与小数可混合，其他值报告 `CN0303`。 |
| `范围` | `止` / `起, 止` / `起, 止, 步长` | 参数必须是整数，左闭右开；步长为 0 报告 `CN0303`，返回新列表。 |

## 列表和通用容器

| 函数 | 参数 | 合同 |
|---|---|---|
| `长度` | `容器` | 文字按码点计数；列表和字典返回项目数。 |
| `追加` | `列表, 项` | 在末尾加入项。 |
| `插入` | `列表, 位置, 项` | 位置必须是整数；负数从末尾计算，超出两端时夹到开头或末尾。 |
| `移除` | `列表, 项` | 用 CNplus 递归相等删除第一个匹配项；没有匹配项报告 `CN0303`。 |
| `弹出` | `列表[, 位置]` | 删除并返回指定项；省略位置取最后一项；空列表或任何越界位置报告 `CN0308`。 |
| `排序` | `列表` | 返回新列表，不修改原列表；项目必须能按 CNplus 数值或文字规则比较。 |
| `倒序` | `列表` | 返回倒序的新列表，不修改原列表。 |
| `包含` | `容器, 项` | 列表使用 CNplus 递归相等；字典检查标签；文字检查子串。 |
| `连接` | `列表, 分隔符` | 把各项转成文字后用分隔符连接。 |

## 字典

| 函数 | 参数 | 合同 |
|---|---|---|
| `所有标签` | `字典` | 按插入顺序返回标签的新列表，内部标签包装不得泄漏。 |
| `所有值` | `字典` | 按插入顺序返回值的新列表。 |
| `有标签` | `字典, 标签` | 按字典标签合同判断是否存在。 |
| `删标签` | `字典, 标签` | 标签存在时删除；不存在时不报错。 |

## 文字

| 函数 | 参数 | 合同 |
|---|---|---|
| `分割` | `文字[, 分隔符]` | 省略分隔符时按连续空白分割；空分隔符时按 Unicode 码点拆分。 |
| `替换` | `文字, 旧, 新` | 替换全部匹配；旧文字为空时在每个码点边界插入新文字。 |
| `查找` | `文字, 子串` | 返回首次出现的码点位置；不存在返回 `-1`。 |
| `去空白` | `文字` | 去掉两端空白。 |
| `大写` | `文字` | 按 Unicode 规则转大写。 |
| `小写` | `文字` | 按 Unicode 规则转小写。 |
| `开头是` | `文字, 前缀` | 判断是否以前缀开头。 |
| `结尾是` | `文字, 后缀` | 判断是否以后缀结尾。 |
