# 十分钟上手 CNplus

> 完全没写过程序也能看懂。跟着敲一遍，十分钟后你会写小程序了。

## 准备

```bash
python -m cnplus 运行 示例/01-你好.cnp
```

看到 `你好，世界！` 就说明装好了。

---

## 一、让电脑说话

新建一个文件 `我的.cnp`，写：

```
打印("你好呀")
```

运行 `python -m cnplus 运行 我的.cnp`，屏幕上就出现 `你好呀`。

`打印` 就是「显示到屏幕上」。引号里的内容原样显示。

---

## 二、给东西起名字

```
设 我的名字 = "小明"
打印(我的名字)
```

`设` 的意思是「建立一个名字」。之后写这个名字，就等于写它代表的东西。

想改它的值，**不用再写「设」**：

```
设 分数 = 60
分数 = 90        ← 改成 90
打印(分数)
```

> 为什么第二次不写「设」？因为「设」是**新建**，名字已经有了就不能重复新建。
> 写第二次会报错 `CN0307`，提醒你是不是不小心用了同一个名字。

**数字和文字要分清**：

```
设 年龄 = 18          ← 数字，可以拿来算
设 年龄文字 = "18"    ← 文字，只能显示
```

想把数字接到文字后面，要先用 `文本(...)` 转一下：

```
打印("我今年" + 文本(年龄) + "岁")
```

直接写 `"我今年" + 年龄` 会报错——CNplus 会告诉你怎么改。

## 三、做判断

```
设 气温 = 32

如果 气温 > 30
    打印("好热")
否则
    打印("还行")
```

注意 `打印` 前面**空了四格**。这个缩进很重要，它表示「这行属于上面那个如果」。

条件必须是**能回答「是/不是」的问题**：

| 写法 | 行不行 |
|---|---|
| `如果 气温 > 30` | ✅ 「气温大于 30 吗」有是/不是的答案 |
| `如果 气温` | ❌ 「气温」不是一个问题 |
| `如果 名字 == "小明"` | ✅ `==` 是「等于吗」 |

> 这点和 Python 不一样，是**故意的**。Python 里 `if 0` 和 `if 1` 都能跑但含义微妙，
> 新手很容易踩坑。CNplus 宁可当场提醒你。

常用的比较：`>` 大于、`<` 小于、`>=` 不小于、`<=` 不大于、`==` 等于、`!=` 不等于。

## 四、重复做事

```
设 次数 = 1

循环 次数 <= 3
    打印("第" + 文本(次数) + "遍")
    次数 = 次数 + 1
```

只要条件还成立，缩进里的内容就一直重复。

`次数 = 次数 + 1` 看着奇怪，但读作「**把次数改成：原来的次数加一**」就通了。
**没有这一行，条件永远成立，程序会停不下来。**

---

## 五、造自己的工具

一段代码要用好几次，就把它做成工具：

```
函数 打招呼(名字)
    返回 "你好，" + 名字 + "！"

打印(打招呼("小明"))
打印(打招呼("小红"))
```

- `函数` 表示「我要造个工具」
- 括号里的 `名字` 是**占位**——用的时候填什么，它就是什么
- `返回` 表示「这个工具算出的结果是……」

## 六、看懂错误提示

写错了不用慌，CNplus 会告诉你三件事：

```
错误[CN0302]: 变量 年龄x 还没有声明过
 --> 我的程序.cnp:2:4
  |
2 | 打印(年龄x)
  |      ^^^^^
  = 也就是说: CNplus 不认识 年龄x，因为你还没告诉它这个名字代表什么
  = 这样改: 是不是想写「年龄」？
```

| 部分 | 含义 |
|---|---|
| `错误[CN0302]` | 错误编号，可以拿去查[诊断码表](spec/03-诊断码.md) |
| `--> 文件:2:4` | 第 2 行第 4 个字 |
| `^^^^^` | 问题就在这几个字上 |
| **也就是说** | 用大白话再讲一遍 |
| **这样改** | 具体怎么办，经常能直接照抄 |

## 七、同一个意思，多种写法

CNplus 的关键字有别名，用你顺口的那个就行，效果完全一样：

| 意思 | 可以写成 |
|---|---|
| 建立名字 | `设` `令` `让` |
| 判断 | `如果` `若` `假如` |
| 否则 | `否则` `不然` `要不然` |
| 重复 | `循环` `当` `重复` |
| 造工具 | `函数` `定义` `过程` |
| 给出结果 | `返回` `返` `给出` |

```
假如 气温 > 30        ← 和「如果 气温 > 30」完全一样
    打印("好热")
```

标点半角全角都认：`打印（1，2）` 和 `打印(1, 2)` 一样。
