# 当事情出错时

程序难免遇到意外：用户输入了乱码、除数是零、文件不存在……
默认情况下，一出错程序就**停下并报错**。用「尝试 / 捕获」可以**接住**
错误，让程序继续。

## 尝试 / 捕获

```
尝试
    设 x = 整数(询问("输入一个数字："))
    打印(填"你输入了 {x}")
捕获 错
    打印("那不是数字，不过没关系")
```

- `尝试` 下面放**可能出错**的代码
- 如果出错了，跳到 `捕获`，`错` 里装着出错的说明
- 如果没出错，`捕获` 整段跳过

不关心错误内容时，`捕获` 后面可以不写变量：

```
尝试
    做点危险的事()
捕获
    打印("失败了")
```

## 最后：无论如何都要做的收尾

```
尝试
    打开文件()
    读取内容()
捕获 错
    打印("读取失败")
最后
    关闭文件()      # 不管成功失败，都会执行
```

`最后` 段**保证执行** —— 哪怕 `尝试` 里 `返回` 了、或者错误没被捕获
继续往上抛，`最后` 都会先跑完。适合放清理资源的代码。

## 抛出：主动制造错误

写函数时，遇到不该发生的情况，可以主动 `抛出`：

```
函数 安全除法(a, b)
    如果 b == 0
        抛出 "除数不能是零"
    返回 a / b

尝试
    打印(安全除法(10, 0))
捕获 错
    打印(填"算不了：{错}")     # 算不了：除数不能是零
```

`抛出` 后面跟一段说明（文字或任何值），这段说明会出现在捕获它的 `错` 里。
没人捕获的话，程序停下并报 `CN0311`。

## 一个实用套路：转不了就给默认值

```
函数 安全转数(文字, 默认 = 0)
    尝试
        返回 整数(文字)
    捕获 错
        返回 默认

打印(安全转数("42"))          # 42
打印(安全转数("abc"))         # 0（转不了，用默认）
打印(安全转数("abc", 默认 = -1))  # -1
```

完整例子见 `示例/16-安全计算器.cnp`。

## 能捕获什么

`捕获` 能接住 CNplus 报出的运行时错误 —— 除以零、类型不对、下标越界、
转换失败、库调用出错、以及你自己 `抛出` 的。语法错误不行（那是运行前
就发现的，程序根本没开始跑）。
