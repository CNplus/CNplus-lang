# 三、重复做

> 让程序把同一件事做很多遍。循环是程序力量感的来源。

## 循环：条件成立就一直做

```cnp
设 次数 = 1

循环 次数 <= 3
    打印("第" + 文本(次数) + "遍")
    次数 = 次数 + 1
```

输出：

```
第1遍
第2遍
第3遍
```

`循环` 只要条件还成立，缩进里的内容就一遍遍重复。这里的 `次数 = 次数 + 1` 是关键——读作「**把次数改成：原来的次数加一**」。

> ⚠️ **没有这一行，条件永远成立，程序会停不下来**（死循环）。写循环一定先想清楚：什么会让条件变成不成立。

## 数数模式

上面的写法是最常见的「计数器」模式，三步走：

```cnp
设 i = 1          # 1. 从几开始
循环 i <= 10      # 2. 做到什么时候停
    打印(i)
    i = i + 1     # 3. 每遍怎么变
```

## 提前退出：跳出

想中途不做了，用 `跳出`：

```cnp
设 i = 1
循环 真
    打印(i)
    i = i + 1
    如果 i > 5
        跳出          # 直接结束整个循环
```

这里 `循环 真` 本来会永远循环，靠 `跳出` 在 i 超过 5 时结束。

## 跳过这一轮：继续

想跳过某几遍但继续循环，用 `继续`：

```cnp
设 i = 1
循环 i <= 5
    如果 i == 3
        i = i + 1
        继续          # 跳过 i=3 这一轮
    打印(i)
    i = i + 1
```

输出 `1 2 4 5`，3 被跳过了。

> `跳出` 的别名是 `中断`，`继续` 的别名是 `下一轮`。效果一样。

## 循环与判断配合

循环里套判断是常见套路。比如「打印 1 到 10 里的偶数」：

```cnp
设 i = 1
循环 i <= 10
    如果 i % 2 == 0
        打印(i)
    i = i + 1
```
