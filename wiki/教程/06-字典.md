# 六、字典

> 用「名字」而不是「编号」来存东西。列表按位置找，字典按键找。

## 什么是字典

```cnp
设 成绩 = {"小明": 85, "小红": 92, "小刚": 78}
```

花括号 `{}` 里是一对对的「键：值」。想查谁的分数，直接用名字查：

```cnp
设 成绩 = {"小明": 85, "小红": 92, "小刚": 78}

打印(成绩["小明"])       # 85
打印(成绩["小红"])       # 92
```

和列表比：列表用编号（`[0]`）取，字典用键（`["小明"]`）取。

## 加一个 / 改一个

```cnp
设 成绩 = {"小明": 85}

成绩["小刚"] = 78        # 没有这个键 → 加进去
成绩["小明"] = 90        # 有这个键 → 改值

打印(成绩)               # {"小明": 90, "小刚": 78}
```

## 查有没有某个键

直接访问不存在的键会报 `CN0308`。想先确认，用 `有键`：

```cnp
设 成绩 = {"小明": 85}

如果 有键(成绩, "小红")
    打印(成绩["小红"])
否则
    打印("查无此人")
```

## 字典的内置函数

| 函数 | 作用 | 例子 |
|---|---|---|
| `键们(字)` | 拿出所有键，成一个列表 | `键们(成绩)` → `["小明", "小红"]` |
| `值们(字)` | 拿出所有值，成一个列表 | `值们(成绩)` → `[85, 92]` |
| `有键(字, 键)` | 有没有这个键 | `有键(成绩, "小明")` → `真` |
| `删键(字, 键)` | 删掉一个键 | `删键(成绩, "小明")` |

```cnp
设 成绩 = {"小明": 85, "小红": 92}

打印(键们(成绩))        # ["小明", "小红"]
打印(值们(成绩))        # [85, 92]
打印(有键(成绩, "小刚")) # 假

删键(成绩, "小明")
打印(成绩)              # {"小红": 92}
```

## 字典配遍历

字典和第七章的 `对于` 遍历是天作之合：

```cnp
设 成绩 = {"小明": 85, "小红": 92, "小刚": 78}

对于 名 在 键们(成绩)
    打印(名 + "：" + 文本(成绩[名]))
```

## 练一练

建一个通讯录 `{"妈妈": "138", "爸爸": "139"}`，加上 `"哥哥": "136"`，再用 `有键` 判断有没有 `"妈妈"` 这个键并打印结果。

<details>
<summary>参考答案</summary>

```cnp
设 通讯录 = {"妈妈": "138", "爸爸": "139"}
通讯录["哥哥"] = "136"

打印(有键(通讯录, "妈妈"))    # 真
打印(通讯录)                  # {"妈妈": "138", "爸爸": "139", "哥哥": "136"}
```

</details>
