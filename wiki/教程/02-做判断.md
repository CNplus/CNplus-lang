# 二、做判断

> 让程序根据条件走不同的路。

## 如果 / 否则

```cnp
设 气温 = 32

如果 气温 > 30
    打印("好热")
否则
    打印("还行")
```

注意 `打印` 前面**空了四格**。这个缩进很重要，它表示「这行属于上面那个如果」。

- `如果` 后面的条件成立，就走缩进里的内容
- 不成立，就走 `否则` 缩进里的内容

> ⚠️ 缩进是 CNplus 的语法，不是装饰。少了缩进会报 `CN0204`（期望缩进块）。

## 比较

条件必须是「能回答是/不是的问题」，常用比较符号：

| 写法 | 意思 |
|---|---|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 不小于（大于等于） |
| `<=` | 不大于（小于等于） |
| `==` | 等于吗 |
| `!=` | 不等于吗 |

```cnp
设 年龄 = 20
打印(年龄 >= 18)     # 真
打印(年龄 == 20)     # 真
打印(年龄 != 20)     # 假
```

> 注意「等于吗」是**两个**等号 `==`。一个等号 `=` 是「赋值」，不是「判断」。

## 严格真值：只有布尔能当条件

CNplus 和 Python 最大的不同之一——**条件必须是布尔**：

```cnp
如果 气温            # ❌ 错误 CN0301：条件必须是布尔值
如果 气温 > 30       # ✅ 这是「是/不是」问题
```

`如果 0`、`如果 ""`、`如果 1` 在 CNplus 里都是**编译错误**，不是「假」也不是「真」。

> 💡 这点是故意的。Python 里 `if 0` 和 `if 1` 都能跑但含义微妙，新手很容易踩坑。CNplus 宁可当场提醒你。

## 多个条件：与 / 或 / 非

| 写法 | 意思 | 别名 |
|---|---|---|
| `甲 与 乙` | 两个都得成立 | `并且` |
| `甲 或 乙` | 有一个成立就行 | `或者` |
| `非 甲` | 反过来 | — |

```cnp
设 年龄 = 20
设 有票 = 真

如果 年龄 >= 18 与 有票
    打印("可以进场")

如果 非 有票
    打印("没票进不去")
```

## 多个分支：嵌套

CNplus 没有 `否则 如果`（elif）这种写法，多分支就在 `否则` 里再套一个 `如果`：

```cnp
设 分数 = 85

如果 分数 >= 90
    打印("优秀")
否则
    如果 分数 >= 60
        打印("及格")
    否则
        打印("不及格")
```

缩进一层层往里，条件从大到小排，程序从上往下找到第一个成立的。

## 练一练

写一个程序：判断一个数是不是偶数。

提示：偶数除以 2 的余数是 0，取余用 `%`。

<details>
<summary>参考答案</summary>

```cnp
设 数 = 8

如果 数 % 2 == 0
    打印(文本(数) + " 是偶数")
否则
    打印(文本(数) + " 是奇数")
```
