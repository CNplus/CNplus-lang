# 七、遍历

> 挨个处理一串东西。比第三章的「数数循环」更省事——不用自己管编号。

## 对于 … 在 …

```cnp
设 同学们 = ["小明", "小红", "小刚"]

对于 名字 在 同学们
    打印(名字)
```

输出：

```
小明
小红
小刚
```

`对于 名字 在 同学们` 读作「对同学们里的**每一个**，叫它『名字』，做下面的事」。它自动从头走到尾，不用像第三章那样自己写 `i = i + 1`。

> `对于` 的别名是 `对每个`。

## 能遍历什么

| 遍历什么 | 得到什么 |
|---|---|
| 列表 | 每个元素 |
| 字典 | 每个**标签** |
| 字符串 | 每个字 |
| 范围 | 一串数字 |

```cnp
# 字典：遍历标签
设 成绩 = {"小明": 85, "小红": 92}
对于 名 在 成绩
    打印(名)              # 小明 / 小红

# 字符串：逐字
对于 字 在 "你好"
    打印(字)              # 你 / 好
```

## 范围

`范围` 造出一串数字，配合遍历是常用套路：

```cnp
对于 i 在 范围(5)
    打印(i)               # 0 1 2 3 4
```

三种写法：

| 写法 | 得到 |
|---|---|
| `范围(5)` | `0, 1, 2, 3, 4` |
| `范围(1, 6)` | `1, 2, 3, 4, 5`（从 1 到 6 的前一个） |
| `范围(1, 10, 2)` | `1, 3, 5, 7, 9`（每次加 2） |

```cnp
对于 i 在 范围(1, 6)
    打印(i)               # 1 2 3 4 5
```

> 注意 `范围(1, 6)` 是 **1 到 5**，不含 6。和编号从 0 开始一样，是约定俗成。

## 遍历配合列表与字典

**统计总分**（遍历列表）：

```cnp
设 分数们 = [80, 90, 70]
设 总分 = 0

对于 分 在 分数们
    总分 = 总分 + 分

打印(总分)                 # 240
```

**打印每个标签和值**（遍历字典的标签）：

```cnp
设 成绩 = {"小明": 85, "小红": 92}

对于 名 在 成绩
    打印(名 + "：" + 文本(成绩[名]))
# 小明：85
# 小红：92
```

## 遍历变量是局部的

`对于` 里的那个名字（比如 `名字`、`i`）只在循环里有效，出了循环就没了：

```cnp
对于 i 在 范围(3)
    打印(i)

# 这里再写 i，会报 CN0302（未声明）
```

## 不能遍历的东西

数字、布尔、空都不能遍历，会报 `CN0309`：

```cnp
对于 x 在 42
# 错误 CN0309：整数不能遍历
```
