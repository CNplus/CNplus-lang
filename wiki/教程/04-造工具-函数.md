# 四、造工具（函数）

> 一段代码要用好几次，就把它做成一个工具，起个名字，以后随叫随到。

## 造一个工具

```cnp
函数 打招呼(名字)
    返回 "你好，" + 名字 + "！"

打印(打招呼("小明"))    # 你好，小明！
打印(打招呼("小红"))    # 你好，小红！
```

三行读懂：

- `函数` 表示「我要造个工具」
- 括号里的 `名字` 是**占位**——用的时候填什么，它就是什么
- `返回` 表示「这个工具算出的结果是……」

## 多个参数

```cnp
函数 加法(甲, 乙)
    返回 甲 + 乙

打印(加法(3, 4))       # 7
```

## 没有返回值的工具

有些工具只是「做一件事」，不「算出结果」。那就不用写 `返回`：

```cnp
函数 报温度(度)
    打印("今天 " + 文本(度) + " 度")

报温度(32)             # 今天 32 度
```

## 函数也是值

CNplus 里函数是「一等公民」——可以像数字、文字一样存进变量、传给别的函数：

```cnp
函数 翻倍(数)
    返回 数 * 2

设 我的工具 = 翻倍        # 把函数存进变量
打印(我的工具(5))         # 10
```

## 自己调自己：递归

函数可以在里面调用自己。经典例子是阶乘（`5! = 5 × 4 × 3 × 2 × 1`）：

```cnp
函数 阶乘(数)
    如果 数 <= 1
        返回 1
    返回 数 * 阶乘(数 - 1)

打印(阶乘(5))           # 120
```

> 递归的关键是「什么时候停」——上面的 `如果 数 <= 1 返回 1` 就是终点。没有终点会无限递归。

## 作用域：函数里和外是两个世界

函数体是**新的作用域**：

```cnp
设 名字 = "小明"

函数 换名字()
    设 名字 = "小红"     # 这是函数里的「名字」，和外面的不一样
    打印(名字)          # 小红

换名字()
打印(名字)              # 小明（外面的没被改）
```

想**修改**外面已有的变量，要用 `外部`：

```cnp
设 分数 = 60

函数 加分()
    外部 分数 = 分数 + 10

加分()
打印(分数)              # 70
```

> `外部` 的别名是 `全局`。不写 `外部` 就赋值，会变成函数里的新变量，外面的不动——这是新手最容易懵的地方。
