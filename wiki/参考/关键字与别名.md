# 关键字与别名

> CNplus 的关键字都有中文别名，用你顺口的那个，效果完全一样。
> 每组第一个是推荐写法。

## 关键字

| 意思 | 可以写成 |
|---|---|
| 建立名字 | `设` `令` `让` |
| 判断 | `如果` `若` `假如` |
| 否则 | `否则` `不然` `要不然` |
| 重复 | `循环` `当` `重复` |
| 造工具 | `函数` `定义` `过程` |
| 给出结果 | `返回` `返` `给出` |
| 外层变量 | `外部` `全局` |
| 真 | `真` |
| 假 | `假` |
| 空 | `空` |
| 并且 | `与` `并且` |
| 或者 | `或` `或者` |
| 取反 | `非` |
| 导入库 | `导入` `引用` |
| 起别名 | `作为` |
| 遍历 | `对于` `对每个` |
| （遍历介词） | `在` |
| 跳出循环 | `跳出` `中断` |
| 跳过本轮 | `继续` `下一轮` |

## 运算符

| 符号 | 意思 |
|---|---|
| `+` | 加（数字）／拼接（字符串） |
| `-` | 减 |
| `*` | 乘（`"哈" * 3` 是字符串重复） |
| `/` | 除（**恒为小数**，`4 / 2` 得 `2.0`） |
| `//` | 整除（向下取整） |
| `%` | 取余 |
| `**` | 幂（右结合，`2 ** 3 ** 2` 得 `512`） |
| `==` | 等于吗 |
| `!=` | 不等于吗 |
| `<` | 小于 |
| `<=` | 小于等于 |
| `>` | 大于 |
| `>=` | 大于等于 |
| `=` | 赋值（不是判断） |

## 标点

`(` `)` `,` `:` `.` `[` `]` `{` `}`

## 全角自动转半角

写中文时顺手用了全角标点也没关系，CNplus 会自动转成半角：

| 全角 | 转成 |
|---|---|
| `，` `（` `）` `：` | `,` `(` `)` `:` |
| `＋` `－` `＊` `／` `＝` | `+` `-` `*` `/` `=` |
| `＜` `＞` `％` `！` | `<` `>` `%` `!` |
| `【` `】` | `[` `]` |
| `“` `”` `‘` `’` | `"` `"` `'` `'` |

所以 `打印（1，2）` 和 `打印(1, 2)` 完全一样。

> 💡 全角转半角只影响语法。**字符串里的全角标点不受影响**——那是你的数据，不是语法。
