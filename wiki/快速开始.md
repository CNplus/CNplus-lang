# 快速开始

> 装好 CNplus，跑起第一个程序。全程约 5 分钟，不需要任何编程基础。

## 一、装

需要 **Python 3.11+** 和 [uv](https://docs.astral.sh/uv/)（Python 的包管理工具）。

```bash
git clone https://github.com/CNplus/CNplus-lang.git
cd CNplus-lang
uv venv --python 3.11 && source .venv/bin/activate
uv pip install -e ".[dev,lsp]"
```

不想用 uv，也可以用系统 pip：

```bash
git clone https://github.com/CNplus/CNplus-lang.git
cd CNplus-lang
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,lsp]"
```

> `[dev,lsp]` 里的 `lsp` 是给编辑器用的，只跑程序的话装 `-e .` 就够了。

## 二、跑第一个程序

装好后，目录里有个 `示例/` 文件夹，里面是 13 个能直接运行的程序。先跑最简单的：

```bash
python -m cnplus 运行 示例/01-你好.cnp
```

屏幕输出：

```
你好，世界！
```

看到这行字，就说明装好了。

> 也可以用 `cnp` 命令代替 `python -m cnplus`，两者等价：`cnp 运行 示例/01-你好.cnp`。

## 三、写自己的程序

新建一个文件 `我的程序.cnp`（扩展名是 `.cnp`），写：

```cnp
设 名字 = "小明"
打印("你好，" + 名字)
```

运行：

```bash
python -m cnplus 运行 我的程序.cnp
```

输出 `你好，小明`。

## 四、命令行速查

| 命令 | 作用 |
|---|---|
| `cnp 运行 x.cnp` | 直接解释执行 |
| `cnp 运行 --python x.cnp` | 转译成 Python 再执行（能借用 pip 库） |
| `cnp 编译 x.cnp` | 生成独立的 `.py` 文件，可到处运行 |
| `cnp 检查 x.cnp` | 只查错，不执行 |
| `cnp 词法 x.cnp` | 打印词元流（调试用） |
| `cnp 语法树 x.cnp` | 打印语法树（调试用） |
| `cnp 版本` | 显示版本 |

## 五、（可选）VSCode 里写

想在编辑器里获得语法高亮、实时中文报错、按 F5 直接运行，装 VSCode 扩展：

```bash
ln -s "$(pwd)/editors/vscode" ~/.vscode/extensions/cnplus
cd editors/vscode && npm install
```

重启 VSCode，打开任意 `.cnp` 文件，就有高亮和波浪线报错了。
