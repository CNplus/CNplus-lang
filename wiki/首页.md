# CNplus —— 使用中文撸代码

> 一门中文编程语言。玩具起步，架构上留有升级成正式语言的出口。

```cnp
设 单价 = 15
设 数量 = 4

打印("总价：" + 文本(单价 * 数量) + " 元")

如果 单价 * 数量 > 50
    打印("满 50 包邮！")
否则
    打印("再买点就包邮了")
```

**没写过程序？** 从[快速开始](快速开始.md)出发，不需要任何基础。
**写过 Python / JS？** 直接看[与 Python 的差异](参考/与Python的差异.md)，一分钟定位区别。

---

## 这是什么

CNplus 让你用中文关键字写程序。它**不是** Python 的「中文函数名封装」，而是有**自己的**词法器（lexer）、语法分析器（parser）和抽象语法树（AST）的独立语言，后端可插拔。

| 特点 | 说明 |
|---|---|
| 🌏 全中文 | 关键字、类型名、错误信息、诊断码全部中文 |
| 🔌 可插拔后端 | 同一份源码，既能直接解释执行，也能转译成 Python |
| 🧱 严格语义 | 刻意和 Python 拉开距离，新手头号坑源被堵死 |
| 💬 三层报错 | 术语 + 大白话 + 能直接照抄的改法 |
| 🗣️ 一意多写 | `设`=`令`=`让`，用顺口的那个 |

### 一个意思，多种写法

用你顺口的那个，效果完全一样：

| 意思 | 可以写成 |
|---|---|
| 建立名字 | `设` `令` `让` |
| 判断 | `如果` `若` `假如` |
| 否则 | `否则` `不然` `要不然` |
| 重复 | `循环` `当` `重复` |
| 造工具 | `函数` `定义` `过程` |
| 给出结果 | `返回` `返` `给出` |

## 为什么要另做一门语言

Python 强大，但对新手有三处「隐式魔法」是坑：`if 0` 能跑但含义微妙、`1 == "1"` 悄悄返回假、变量没声明也能等到运行时才炸。CNplus 的选择是**当场提醒**：

| 主题 | CNplus | Python |
|---|---|---|
| 真值 | 只有 `真`/`假` 能出现在条件位置，`如果 0` 是编译错误 | 隐式真值 |
| 跨类型比较 | 数 vs 串比较报错 | 返回 `False` |
| 未声明变量 | 编译期错误 | 运行时 `NameError` |

## 架构：玩具与正式语言的分界线

```
源码 .cnp
  → lexer（词法）→ parser（AST）→ checker（静态检查）→ 后端（执行）
```

CNplus 有**自己的** lexer、parser 和 AST，后端可插拔。首发两个后端，行为逐字一致：

| 后端 | 命令 | 特点 |
|---|---|---|
| 树遍历 | `cnp 运行 x.cnp` | 直接解释执行，启动快，报错精准 |
| Python 转译 | `cnp 运行 --python x.cnp` | 先翻成 Python 再跑，能借用 pip 生态 |
| Python 编译 | `cnp 编译 x.cnp` | 生成独立的 `.py`，拷到别处也能跑 |

这一点是本项目的全部要害：将来换成字节码 VM 或 JS 后端，**前端一行不用改**。

## 快速开始

```bash
git clone https://github.com/CNplus/CNplus-lang.git
cd CNplus-lang
uv venv --python 3.11 && source .venv/bin/activate
uv pip install -e ".[dev,lsp]"

python -m cnplus 运行 示例/01-你好.cnp    # 你好，世界！
```

看到 `你好，世界！` 就装好了。详见[快速开始](快速开始.md)。

## 历史

CNplus 始于 2021 年 12 月，最初是一层中文函数名封装；2022 年 6 月尝试用 C++ 重做成 IDLE，停在 `main.cpp:28` 一个没写完的 `cout` 上。2026 年重启，这次先建「源码 → AST」与「AST → 执行」之间的接缝，再建楼。老仓库原样保存在 `archive/` 下作只读参考。
