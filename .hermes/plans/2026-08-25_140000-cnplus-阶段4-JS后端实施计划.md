# CNplus 阶段 4 实施计划：JS 转译后端 + REPL + 在线运行器（v1.0.0 线）

> **For Hermes:** 按任务顺序执行，每个任务走完整 TDD 循环（失败测试 → 最小实现 → 通过 → 提交）。
> 拍板：2026-08-25，用户批准路线 C（先 JS 后端，VM 降为阶段 5）。
> 版本策略：**从第一个任务落地起即发 1.0.0 系列版本**（用户拍板）——
> 1.0.0-alpha.1、1.0.0-alpha.2……全部完成、三后端对拍全绿后转正 1.0.0。

**Goal:** 给 CNplus 加 JS 转译后端（浏览器/Node 执行）、`cnp 交互` REPL、官网在线运行器，全程用黄金语料做三后端对拍，发版 1.0.0。

**Architecture:** 复用铁律 3 的 `Backend` 抽象——JS 后端 = `js_emit/`（发射器，Python 写，生成 JS）+ `运行时源码.js`（内联运行时，移植自 `运行时源码.py`）。每条生成语句调用运行时函数，保证 CNplus 语义（严格真值、`/` 恒小数、块级作用域）不泄漏 JS 语义。REPL 复用树遍历后端 + 环境链暂存。在线运行器是纯静态页，调用同一运行时的浏览器构建。

**Tech Stack:** Python 3.11（发射器/CLI）、Node ≥18（对拍执行 + 浏览器兼容基线）、pytest（对拍测试）、Monaco/Monarch（playground 高亮，从 keywords.toml 生成）。

## Task 2: JS 运行时核心——值与环境（含 4/2=2.0 语义）

**Objective:** `运行时源码.js` 实现值类型判定、显示、环境链（声明/取/赋值），语义与 `运行时源码.py` 逐字一致。**先在 Python 里单测运行时 JS 源码**（node 执行断言），再接对拍。

**Files:**
- Create: `cnplus/backends/js_emit/运行时源码.js`
- Test: `tests/test_js运行时.py`

**Step 1: 写失败测试**（node 断言 JS 运行时的语义）

```python
def test_JS运行时_除法恒为小数():
    码 = "console.log(显示(除(4, 2, 0, 0)))"
    out = node跑(码)
    assert out == "2.0"      # 不是 JS 原生的 2！
```

关键语义点（每个一条测试）：
- `显示(除(4,2))` → `2.0`（JS 原生 4/2 是整数 2——运行时必须包 Number.isInteger 转 x.0）
- `显示(真)` → `真`；`显示(空)` → `空`
- 环境链：`环境.取('x')` 找父链；找不到报 CN0302（错误对象带码/消息/行列）
- 类型名：`类型名(3.14)` → `小数`

**Step 2:** 跑测试确认失败（运行时文件不存在）
**Step 3:** 实现运行时核心（class 环境、CNplus错误、显示、类型名、四则运算函数、条件/非——严格真值）
**Step 4:** 跑测试绿
**Step 5:** Commit: `feat(js): 运行时核心——值/环境/运算，严格真值与除法恒小数`

## 风险与对策

| 风险 | 对策 |
|---|---|
| JS Number 整数精度（>2^53 失真） | 运行时加安全整数检查：字面量/运算结果超 ±2^53-1 报 CN0303「数字太大」——教学场景这是异常路径，主动报错优于悄悄失真 |
| `-0`、`NaN`、`Infinity` 渗入 | 显示() 里防御：`-0` 显示 `0`；NaN/Infinity 报错（除零本就被 CN0304 拦截） |
| 询问() 浏览器不可用 | 运行时检测输入通道，无则报中文错误说清「网页版暂不支持输入」 |
| node 版本差异 | package.json engines 声明 ≥18；对拍测试无 node 自动 skip（不阻塞他人跑测试） |
| 工期溢出 | 每任务独立可发版（alpha 节奏），不会烂尾 |
