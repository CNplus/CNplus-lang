# CNplus 重启：方案 B 实施总纲

> **性质**：长期主纲领，不是一次性任务单。每完成一个阶段回来更新「进度看板」和「决策日志」。
> **给 AI 助手**：实现时逐任务执行，每个任务都是 TDD 五步（写失败测试 → 跑并确认失败 → 最小实现 → 跑并确认通过 → 提交）。不要跳步，不要合并任务。

**创建日期**：2026-08-21
**前身**：`archive/CNplus-python`（2021-12 ~ 2022-05，已弃用）、`archive/CNplus-mixed`（2022-06 ~ 2022-07，编译失败于 `main.cpp:28` 一个未写完的 `cout`）

## 一、目标

做一门**中文编程语言**，玩具起步，但架构上留有升级成正式语言的出口。

**一句话架构**：自有 lexer + parser + AST，后端可插拔；首发后端把 AST 转译成 Python 源码，将来可换成字节码 VM 或别的目标语言，**前端一行不改**。

**核心判断**：玩具和正式语言的分界不在功能（GC、类型系统、VM），而在「源码 → AST」和「AST → 执行」之间有没有一条干净的接缝。有缝，换后端是一个周末；没缝，任何升级都是重写。

**这次要修正的历史错误**：
- `CNplus-python` 只有一层中文函数名封装，没有自己的表示 → 无法演进
- `CNplus-mixed` 用 `string::find` 子串匹配派发，连 token 都没有 → 只能从零重来

两次都是字符直接跳到执行，中间层不存在。**这次先把中间层建起来。**

## 二、不可回填的五条铁律（第一天必须做对）

这五条现在做几乎不花钱，事后补要重写前端。任何任务与之冲突，以本节为准。

### 铁律 1：自有 AST 节点
不用 Python 的 `ast` 模块，不用裸 dict。节点是 **CNplus 的语义单位**，不是宿主的。
> 反例（假方案 B）：节点叫 `IfNode` 但字段结构照抄 Python 的 `ast.If`。那只是换个写法的关键字替换，缝仍然不存在。

### 铁律 2：万物带 Span
**每个 token、每个 AST 节点**都带 `Span`（起止行、列、字节偏移）。
这是最多人跳过、也最不可能回填的一条。错误信息、source map、调试器、LSP 全建在 span 上；事后加 span 等于把整个前端重写一遍。

### 铁律 3：后端接口先于第二个后端存在
第一天就定义 `Backend` 抽象基类，哪怕只有一个实现。有它，第二个后端才是「加文件」而不是「改架构」。

### 铁律 4：关键字表是数据
一张 `cnplus/lexer/keywords.toml`，不硬编码字符串。免费换来：简繁两套、方言别名、英文回退，且语法高亮 / LSP 读同一张表。

### 铁律 5：黄金测试语料
`tests/golden/` 下每个用例一个目录（源文件 + 期望输出），一键全跑。
**这是将来敢重写后端的唯一保险。** 没有它，写完 VM 你不知道行为变了没有。

## 三、最大陷阱：语义泄漏（必须主动防御）

转译到 Python 会让 CNplus **悄悄继承 Python 的语义**：整除行为、真值判断、数值精度、作用域规则、求值顺序。

危险在于：黄金语料记录的会是「Python 恰好这么干」，而不是「CNplus 规定这么干」。等阶段 4 换成自有 VM，一大批程序会以说不清原因的方式坏掉。

**对策（成本很低，必须做）**：
1. 先写 `docs/spec/00-语义约定.md`（两页，见下）
2. 测试断言**规定的行为**，不是观察到的宿主行为
3. 凡「Python 这样所以这样」的地方，显式标记为**未定义行为**，不让用户依赖

这一步区分「一门语言」和「一张 Python 的面具」。

## 四、语义约定（阶段 0 前先定稿）

写进 `docs/spec/00-语义约定.md`。以下是提案，实现前需确认。

| 主题 | 规定 | 与 Python 的差异 |
|---|---|---|
| **整数** | 任意精度 | 同 |
| **除法** | `/` 恒为浮点；`//` 向下取整 | 同（但要写下来，不能靠继承） |
| **真值** | **只有 `真`/`假` 能出现在条件位置**。`如果 0` → 编译错误 | **不同**。Python 的隐式真值是初学者头号坑源 |
| **相等** | `1 == 1.0` 为真；跨类型（数 vs 串）比较 → 错误，不是 `假` | **不同** |
| **作用域** | 函数体是新作用域；赋值即声明本地；改外层需 `外部` 关键字 | 近似，但显式化 |
| **求值顺序** | 严格从左到右，包括函数实参 | 同 |
| **未初始化** | 读未声明变量 → 编译期错误（不是运行时 NameError） | **不同**，更早报错 |
| **字符串** | 不可变，Unicode 码点序列 | 同 |
| **错误** | 所有运行时错误携带 span + 稳定诊断码 | 不同（Python 只有 traceback） |

> 「真值」和「跨类型相等」这两条是**故意和 Python 不一样**的——它们既服务初学者（早报错、报得准），又证明前端确实是自己的，而不是 Python 的皮。

## 六、阶段路线

每个阶段结束都产出**能跑的东西**。不允许出现「写了三周还跑不起来」的阶段。

> **实际完成情况**（2026-08-21）：阶段 0 与 0.5 一次做完，
> 实际代码约 2400 行（估 600 行偏低，主因是错误恢复、静态检查、
> 诊断渲染这些「为编辑器服务」的部分比预想重）。162 个测试。

| 阶段 | 产出 | 规模 | 出口价值 |
|---|---|---|---|
| **0** | lexer + Pratt 解析 + 树遍历求值 | ~600 行 → **实际 ~1500** | 此时它已经是真语言，只是很小 |
| **0.5** | VSCode 扩展：高亮 + 红波浪线 + 运行按钮 | ~150 行 | 「像门真语言」的 80% 观感，一天可得 |
| **1** | Python 转译后端 + source map | +300 行 | 能 `导入` Python 库，玩具有了实用价值 |
| **2** | 中文诊断系统（源码摘录 + 波浪线 + 修复建议） | +400 行 | span 的第一次分红；面向初学者的主卖点 |
| **3** | REPL + LSP（复用同一前端） | +500 行 | 2022 年 C++ 版想做的 IDLE，到这里才算真做成 |
| **4** | **出口**：字节码 VM ／ 第二个 emit 目标（JS） | — | 前端与语料原封不动 |

### 阶段 0 详细任务（TDD，每个 2–5 分钟，共 16 个）

> 顺序不可打乱：Span → 诊断 → 关键字 → 归一化 → lexer → AST → parser → 后端接口 → 求值器 → CLI → 语料

- **0.1** `git init` + `pyproject.toml` + `uv python pin 3.11` + 首次提交
- **0.2** `source.py`：`Position(行,列,偏移)` / `Span(起,止)` / `SourceFile`。测试：span 合并、切片取原文
- **0.3** `diagnostics.py`：`Diagnostic(码, 消息, span, 提示)` + `DiagnosticBag`。渲染器输出源码摘录 + `~~~` 波浪线。测试：单行 / 跨行 / 中文宽字符对齐（**宽字符对齐是坑，务必测**）
- **0.4** `keywords.toml` + 加载器。含简繁双写、英文回退。测试：`如果`/`若`/`if` 映射到同一 `TokenKind.IF`
- **0.5** `normalize.py`：`，（）：""` → `,():""`。**只在 lexer 入口做一次**，绝不渗到 parser。测试：混合全半角源文件
- **0.6** lexer：数字、字符串、标识符（含中文）、标点、注释。每个 token 带 span
- **0.7** lexer 错误路径：未闭合字符串、非法字符 → 诊断而非崩溃
- **0.8** `ast.py`：节点定义（`字面量` `变量` `二元` `一元` `调用` `令` `赋值` `如果` `循环` `函数` `返回` `表达式语句`）。全部 `@dataclass(frozen=True)` 且带 `span`
- **0.9** Pratt 表达式解析：字面量、一元、二元（优先级表）、括号、函数调用
- **0.10** 语句解析：`令 x = 1`、赋值、`如果/否则`、`循环`、`函数`、`返回`
- **0.11** **parser 错误恢复**（为编辑器而生，见 D-005）：AST 加 `错误节点`；恐慌模式跳到同步点（行首/换行/关键字）继续；parser **恒返回 `(AST, 诊断列表)`，永不抛异常**。测试：残缺输入（`令 x =` / `如果` 后无体）仍产出可用 AST 且报告诊断
- **0.12** `backends/base.py`：`Backend` ABC，定义 `执行(程序) -> None`
- **0.13** `treewalk/`：环境链 + 求值器。**在这里落实「条件必须是布尔」等语义约定**
- **0.14** `builtins.py`：`打印` / `判断` / `随机数`（沿用 2021 年那三个函数的签名，算是接上）
- **0.15** `cli.py`：`cnp 运行 x.cnp`、`cnp 词法 x.cnp`、`cnp 语法树 x.cnp`（后两个是调试出口，等于把 2022 年的「下标查找器」做正规）
- **0.16** `test_golden.py` 语料驱动 + 头 10 个用例（含 3 个错误用例）

**阶段 0 验收**：以下程序能跑通并输出正确结果

```
函数 阶乘(n)
    如果 n <= 1
        返回 1
    否则
        返回 n * 阶乘(n - 1)

令 i = 1
循环 i <= 5
    打印(阶乘(i))
    i = i + 1
```

同时 `如果 0` 必须报出带波浪线的中文错误 `CN0201: 条件必须是布尔值`。

### 阶段 0.5 详细任务：编辑器初体验

> **不自研 IDE，做 LSP。** 见 D-006。本阶段只依赖阶段 0 已有的东西，一天可完成，却拿到「像门真语言」的 80% 观感，并端到端验证 span 是通的。

VSCode 体验分五层，本阶段只做前三层：

| 层 | 能力 | 依赖 | 阶段 |
|---|---|---|---|
| 1 | 语法高亮、括号匹配、注释快捷键、文件图标 | 无（TextMate 正则） | **0.5** |
| 2 | 错误波浪线 | lexer + parser + 诊断 | **0.5** |
| 3 | 运行按钮 / F5 | CLI | **0.5** |
| 4 | 悬停、补全、跳转定义、重命名、大纲 | 符号表 + 作用域解析 | 3 |
| 5 | 断点调试、单步、变量查看 | DAP + 求值器可暂停 | 4+ |

- **0.5.1** `tools/生成语法文件.py`：从 `keywords.toml` 生成 `.tmLanguage.json`。**绝不手写**（见 D-007）。测试：加一个关键字后重跑，语法文件同步变化
- **0.5.2** `editors/vscode/package.json`：注册 `.cnp` 语言、扩展名、图标、注释规则、括号对
- **0.5.3** 本地安装验证：`ln -s` 到 `~/.vscode/extensions/`，打开 `.cnp` 文件确认高亮（**无需发布市场**）
- **0.5.4** `cnplus/lsp/server.py`：`pygls` 起 server，只实现 `textDocument/didOpen` + `didChange` → 跑 lexer+parser → 推 `publishDiagnostics`。**复用同一前端，零重复实现**
- **0.5.5** VSCode 客户端壳（~50 行 TS）：拉起 server 进程，接管 `.cnp`
- **0.5.6** 端到端验证：编辑器里敲 `如果 0`，当场出红波浪线 + 中文消息 `CN0201`
- **0.5.7** `tasks.json` 运行配置：F5 跑当前 `.cnp` 文件

**刻意不做**（见 D-008）：增量解析（万行以前整文件重解析够用）、自研 REPL 图形界面（图形交给 VSCode）。

### 阶段 1–4 提要（到时展开）

- **阶段 1**：`python_emit` 后端。**难点是 source map**——CNplus 行号 ↔ 生成的 Python 行号；Python 抛异常时要能翻译回 CNplus 位置。`导入` 语句打通 pip 生态。
- **阶段 2**：诊断升级。参考 Rust/Elm——错误信息本身就是核心特性，对中文初学者语言更是主卖点。加「你是不是想写…」的拼写建议（编辑距离）。
- **阶段 3**：REPL（增量解析、多行输入）+ LSP（补全、悬停、实时诊断）。复用同一 lexer/parser，**零重复实现**。
- **阶段 4**：二选一或都做。VM 路线走《Crafting Interpreters》clox 结构（栈式字节码）；JS 路线让 CNplus 在浏览器直接跑，教学场景杀手级。**多后端才是真尾巴**：AST 边界干净时，加一个目标语言是一个周末的事。

| D-008 | 2026-08-21 | 不做增量解析、不自研 REPL 图形界面 | YAGNI。万行以前整文件重解析够用；图形交给 VSCode |

| D-010 | 2026-08-21 | 短路运算未求值的一侧不做类型检查（静态与运行时皆然） | 短路语义的必然代价：未执行的代码没有值可检查。静态检查若下钻短路右侧，`真 或 1 / 0` 会被误报 |
| D-011 | 2026-08-21 | 仓库名 `CNplus-lang` 而非 `CNplus` | GitHub 保留了已删除的 `CNplus/CNplus` 名称，不可重用。`-lang` 反而更准（明示语言本体，与 `CNplus-python`/`CNplus-mixed` 并列） |
| D-012 | 2026-08-21 | 字符串字面量内容取原文，不取归一化后文本 | 全角标点在字符串里是**数据**不是语法。`"你好，世界！"` 里的 `，！` 必须原样保留。由黄金语料 0001 抓到 |
| D-013 | 2026-08-21 | 转译后端 = 发射器 + 内联运行时，不直接翻译成 `a+b` | 直接翻译会让生成代码用 Python 语义（`if 0`、`1=="1"`），语义泄漏。每步运算调运行时，两后端对拍逐字一致 |
| D-014 | 2026-08-21 | 生成的 `.py` 自包含，内联整个运行时，不 import cnplus | 用户要「写真实软件」「拷到别处运行」。生成文件必须能脱离 CNplus 独立跑 |
| D-015 | 2026-08-21 | 借用 Python 库走 `导入 "库名" 作为 别名` + `.` 成员访问 | 库名是 Python 世界的英文名，保留引号里；别名给中文。这是接入 pip 生态的最小面 |
| D-016 | 2026-08-21 | 集合类型名「列表」「字典」，遍历 `对于 x 在 …`，`跳出`/`继续`，都给白话别名 | 用户拍板。跟大多数语言一致，降低跨语言迁移成本 |
| D-017 | 2026-08-21 | 内置函数只此一张表，两后端共用；静态检查名单从表自动读 | 曾因硬编码名单漏认 8 个新内置函数。自动读取杜绝再漏 |
| D-018 | 2026-08-21 | 跳出/继续 编译成 Python 原生 break/continue，不用异常 | 转译后端里 for 循环直接用原生控制流，比抛异常快且干净 |
| D-019 | 2026-08-21 | 中文库包装层（`导入 数学库` API 也中文）推迟到语言稳定后 | 用户提议但认可须等语言站稳，否则包装层随语言变动反复重写 |
| D-035 | 2026-08-22 | 插值串前缀由关键字 `填` 改为符号 `@`，保留内部 `{}` 边界 | 用户指出 `填"…"` 动宾错位：填的不是那个字符串而是串内的空。符号不声称动宾关系。中文无词边界，去掉 `{}` 会导致 `@年龄+1` 无法确定变量止于何处，故大括号是必需边界而非冗余 |
| D-033 | 2026-08-21 | 内置名放父作用域/父环境，用户顶层是子作用域 | 遮蔽内置名必须允许且两后端一致；重复声明检查只针对用户自己的声明。三处（checker/树遍历/转译）必须同时改，否则后端分叉 |
| D-034 | 2026-08-21 | 索引复合赋值 `字典[键] += 1` desugar 成 `字典[键] = 字典[键] + 1` | 复用现有索引赋值节点，两后端零特殊处理；下标表达式会求值两次，当前无副作用下标故可接受 |
| D-030 | 2026-08-21 | 异常处理用 尝试/捕获/最后/抛出，映射到 Python try/except/finally/raise | 双字动词直白；「最后」用 finally 保证任何路径都执行 |
| D-031 | 2026-08-21 | 库/内置异常在调用点就包成 CNplus错误，不留到顶层 traceback 推断 | 这样「捕获」在生成代码里能用 except CNplus错误 接住；span 也更准 |
| D-032 | 2026-08-21 | 常见错误（类型转换）文本两后端对齐，罕见库错允许不同 | 用户拍板的折中：核心可预期错误逐字一致，长尾库错只保证能捕获 |
| D-029 | 2026-08-21 | 输入函数定名 `询问` / `询问数值`（弃 `问`/`问数字`）；示例函数名避免单字歧义（`除`→`相除`） | 单字动词太短、像虚词；「数字」是字形、「数值」是量。**单字命名易歧义，面向用户的名字优先用双字完整词** |

| D-026 | 2026-08-21 | 格式串用 `填"…{表达式}…"`，不用 Python 的 f 前缀 | 「填」= 填空，`{}` 就是要填的空，符合「名字要能联想到用途」。f 是无意义字母 |
| D-027 | 2026-08-21 | 多返回值 `返回 甲, 乙` 编译成列表，解包按长度校验 | 不引入独立的元组类型（列表够用），少一个概念 |
| D-028 | 2026-08-21 | 内置函数读输入必须区分「空行」和「输入结束」 | EOF 返回 None 而非 ""；`问数字` 遇 None 抛 EOFError 由调用点包装成 CN0310。**教训：EOF 当空串会导致重试死循环，真实卡死过** |

## 九、如何续写本计划

1. **阶段展开**：动工某阶段前，把「提要」拆成 0.1 那样的 2–5 分钟任务列表，追加到本文件对应小节。
2. **决策**：任何架构变更先在决策日志追加一行，重大的另写 `docs/decisions/NNNN-*.md`。
3. **铁律不可协商**：第二节五条与任何后续任务冲突时，以铁律为准；确需违反必须写 ADR 说明。
4. **语料只增不删**：修 bug 时先加语料复现，再修。语料是资产。
5. **每阶段末回填**：更新进度看板 + 记录实际行数/耗时，用于校准后续估算。
